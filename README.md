# 闲鱼选品、归档和上架技能

包含三个技能目录：`skills/xianyu-discover`（选品）、`skills/xianyu-archive`（归档）、`skills/xianyu-publish`（准备上架，最终由用户手动发布）。各目录包含技能说明及其引用的契约和脚本。

这是从原环境提取的版本，**尚未完成 WorkBuddy 适配**。部分技能仍依赖原环境的工作台、数据库、本机路径和浏览器工具；在其他电脑或 agent 中使用前，需要根据实际环境调整并验证。技能不包含闲鱼登录状态、商品档案或图片。

执行时保持闲鱼页面访问间隔至少 10 秒；归档和发布流程的其他约束见各技能的 `SKILL.md`。
